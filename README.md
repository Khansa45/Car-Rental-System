# Car Rental System (ASP.NET Core MVC)

A web-based Car Rental System built using ASP.NET Core MVC architecture. Users can view available cars, book them dynamically, and view the updated list of booked cars.

## Features
- **Available Cars:** Displays all available cars in a responsive Bootstrap grid layout.
- **Booked Cars:** Displays booked cars in a structured table.
- **Dynamic Booking:** Moves selected cars from available to booked list in real-time.

## Tech Stack
- **Framework:** ASP.NET Core MVC
- **Language:** C#
- **Frontend:** Razor Views, HTML, Bootstrap 5
